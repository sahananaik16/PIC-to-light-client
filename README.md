# PIC-to-light-client
The client part of the PIC to Light project serves as the user interface for managing the warehouse inventory system. It runs on a host device (such as a computer) and communicates with the PIC18F4580 microcontroller over the UART protocol. The client sends commands to the master, which relays them to the appropriate slave devices using the CAN protocol. The client interface allows the user to interact with the system, send commands to update the inventory, request status updates, and perform other management tasks. It is responsible for sending data, such as inventory requests or commands to specific slaves, based on the user’s actions. The system uses a unique ID for each slave, ensuring that the master can identify and communicate with the correct device. The client part of the system also receives responses from the slaves through the master, displaying real-time updates about the inventory status or any relevant data. The interface can be designed to be intuitive, displaying the warehouse’s stock levels, allowing for inventory adjustments, and providing feedback to the user regarding the success or failure of each transaction.
